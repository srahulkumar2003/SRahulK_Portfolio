# Kiro Guide

Open this folder in Kiro:

```text
rahul-interactive-engineer-portfolio
```

Then run:

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

Main files to edit:

```text
src/App.jsx
src/styles.css
src/data/portfolio.js
```

Where to add your manual project links:

```text
src/data/portfolio.js
```

Inside each project, replace:

```js
live: '#',
github: '#',
```

with your real Live Demo and GitHub links.

Important assets:

```text
public/assets/intro/rahul-black-white-intro.mp4
public/assets/projects/
public/assets/logos/
public/assets/certificates/
public/assets/research/
public/assets/documents/
```
